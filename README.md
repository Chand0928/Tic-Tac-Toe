# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.  
This project demonstrates core front-end concepts such as DOM manipulation, event handling, and basic game logic.

🔗 **Live Demo:**  
https://chand0928.github.io/Tic-Tac-Toe/

---

## 📌 Features

- 🎯 Two-player game (Player X vs Player O)
- 🧠 Automatic win and draw detection
- 🔄 Restart game functionality
- 🎨 Clean and responsive UI
- ⚡ Fast and lightweight (no libraries used)

---

## 🛠️ Tech Stack

- **HTML** – Structure of the game board  
- **CSS** – Styling and layout  
- **JavaScript** – Game logic and interactivity
